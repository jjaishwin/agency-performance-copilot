# Business case: time saved for account managers

This is an estimate to frame a pilot, not a measured result. Every input is an assumption to be replaced with real numbers by shadowing account managers.

## Formula

```
Hours saved per year = account managers × client calls per week × minutes saved per call ÷ 60 × working weeks
```

## Example with stated assumptions

| Input | Assumption | How to validate |
|---|---|---|
| Account managers using the tool | [e.g., 50] | Pilot group size |
| Client calls needing prep, per AM per week | [e.g., 8] | Shadow 5 account managers |
| Minutes saved per call (prep without vs with the agent) | [e.g., 20] | Time both ways during the pilot |
| Working weeks | 46 | |

With those example inputs: 50 × 8 × 20 ÷ 60 × 46 ≈ **6,100 hours a year**, or about 2.6 hours per account manager per week, back for selling.

## How success is measured in a pilot

| Measure | Target |
|---|---|
| Weekly active account managers | [e.g., ≥ 70% of the pilot group] |
| Minutes saved per call (measured) | [validate the assumption] |
| Benchmark accuracy | ≥ 14/15, maintained after every change |
| Questions answered without an analyst request | Trending up |
| Thumbs-down rate in Genie Monitoring | Trending down |
